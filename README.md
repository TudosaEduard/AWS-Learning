# AWS Learning Path

## AWS Certified Cloud Practitioner

The AWS Certified Cloud Practitioner exam is the entry-level AWS certification. It checks whether you understand AWS at a broad, foundational level, not whether you can deeply architect or administer production systems.

AWS describes it as validating a foundational, high-level understanding of AWS Cloud, services, and terminology, and it is meant for people who can demonstrate overall AWS Cloud knowledge independent of a specific job role
